Project Overview

This project implements a complete CI/CD pipeline for a Laravel application using GitHub Actions. The pipeline includes automated testing, staging deployment, and production deployment stages.

Phase 2: Deployment Script

2.1 deploy.sh

File: deploy.sh

Seven-step deployment process:

#!/bin/bash
set -e

# Step 1: Enable maintenance mode
php artisan down

# Step 2: Pull latest changes
git pull origin main

# Step 3: Install dependencies
composer install --no-interaction --prefer-dist --optimize-autoloader --no-dev

# Step 4: Run migrations
php artisan migrate --force

# Step 5: Optimize application
php artisan optimize

# Step 6: Restart queue workers
php artisan queue:restart

# Step 7: Disable maintenance mode
php artisan up

Phase 3: GitHub Actions Pipeline

3.1 Workflow Configuration

File: .github/workflows/deploy.yml

3.2 Pipeline Stages

Stage 1: Build

  • Checkout code
  • Setup PHP 8.3
  • Install Composer dependencies
  • Upload vendor directory as artifact

Stage 2: Test

  • Download vendor artifact from build stage
  • Setup PHP environment
  • Copy .env.example to .env
  • Generate application key
  • Create SQLite database
  • Run PHPUnit tests

Stage 3: Staging

  • Runs after successful tests
  • Simulates staging deployment
  • Executes on all branches

Stage 4: Production

  • Conditional execution: only on main branch
  • Uses production environment
  • Echoes 7-step deployment process
Branch Strategy: Pipeline triggers on push/PR to main and feature/* branches

Phase 4: Testing & Simulation

4.1 Red Pipeline (Failure Simulation)

Steps to create failing test:

  1. Open tests/Feature/TaskTest.php
  2. Navigate to line 21 in test_can_list_tasks()
  3. Change: $response->assertStatus(200);
  4. To: $response->assertStatus(404);
  5. Commit changes: git commit -am "Test: Simulate pipeline failure"
  6. Push to GitHub: git push origin [branch-name]
  7. Observe pipeline failure in GitHub Actions tab
  8. Take screenshot of red/failed pipeline

4.2 Green Pipeline (Success)

Steps to fix and pass tests:

  1. Revert change in tests/Feature/TaskTest.php line 21
  2. Change back: $response->assertStatus(200);
  3. Commit fix: git commit -am "Fix: Restore correct test assertion"
  4. Push to GitHub: git push origin [branch-name]
  5. Observe successful pipeline in GitHub Actions
  6. Take screenshot of green/passing pipeline
